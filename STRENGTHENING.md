# Independent validation and completion-policy analyses

This source-only extension adds explicit information-boundary tests, independent Michigan/Washington cohorts, endpoint and follow-up-selection diagnostics, and unequal-probability full-schedule completion. The previous numerical analysis files are preserved. A subsequent presentation-only revision updates the current plotting helpers and renderers to normal text weight. Run the added stages with `run_strengthening.py`; the historical `run_pipeline.py` remains available.

## Setup and quick checks

```bash
pip install -r requirements-strengthening.txt
python run_strengthening.py test
python -m unittest discover -s tests -v
```

The 15 added no-data tests exercise the actual helpers used by the new pipeline: exact identifier mapping and exclusion of incomplete UCMR5 members, verified per-source event counts, 366/367-day boundaries without later-window searching, censoring before averaging, first-complete-calendar selection, actual-state-end follow-up opportunity, weighted AUC with ties, exact label-scenario AUC extrema, enumerated variable-completion variance, the nonnegative fixed-coefficient variance identity, q=1 Hájek equivalence, self/own-region neighbour exclusion and target-label/category invariance. They are software/scientific-identity checks, not new field validation.

Paths use `--workdir <directory>` (default: repository root). The historical pipeline should first create `data_derived/frame_systems.parquet`, `small_frame_anchor.parquet`, `ucmr5_all.parquet`, and `results/within_system_rules.parquet`. Derived input schemas and limitations below are essential; a newer public download is not the frozen study snapshot. Optional overrides are `--derived-dir`, `--external-raw-dir`, `--wa-raw-dir`, `--results-dir`, `--external-results`, `--spatial-results`, `--method-results` and `--figure-dir`. Each maps to the corresponding `ANCHOR_*` path in `strengthening/paths.py`. No private absolute path is embedded in the extension.

## Input schemas

- `frame_systems.parquet`: one row per PWSID; current inventory size class, population, source/system attributes, administrative ZIP-centroid coordinates, EPA region, and retained UCMR5 `y_mcl`/`y_det`. The study frame contains 66,395 rows. `strengthening/spatial/spatial_transfer.py:setup` lists the precise feature fields.
- `small_frame_anchor.parquet`: 56,591 current small systems with frozen original `f` and `u`, floored service population `P`, `src`, source-by-size `cell`, coordinates, inventory attributes and observed `y_mcl` (970 complete observations). The extension does not replace these frozen fields.
- `ucmr5_all.parquet`: all occurrence rows with PWSID and PWSName; all 10,313 unique member IDs, including incomplete outcomes, are excluded from external validation.
- `within_system_rules.parquet`: historical full/reduced schedule outcomes and event costs, with `size_cat`, `y`, `yt_R1`, `yt_R12`, `cost_full`, `cost_R1`, and `cost_R12`; generated by the original schedules stage. New completion policies use only this historical small-system pilot for missed-outcome/cost calibration.
- Michigan/Minnesota/New Hampshire inputs retain the paths/schemas in [DATA_SOURCES.md](DATA_SOURCES.md). Washington adds four official files under `external_raw/wa_doh_20261031/`; see `strengthening/washington_sources.json` for URLs and frozen SHA256 values. Washington general/source workbooks contain public contact fields that are unused; raw workbooks must stay local and are excluded by `.gitignore`.


Each region-excluded model omits the target EPA region from classifier supervision and neighbour-label references. Category maps are fit on training data only. The no-administrative-ID ablation is an exploratory diagnostic, retained alongside its original comparison rather than relabelled a blind test. Full prediction frames remain local.

Before summarizing, run `python run_strengthening.py join-spatial-diagnostics` to join the no-ID diagnostic by exact PWSID without altering the original prediction file. Regional summary commands accept `--predictions`, `--frame`, `--out` and, for the coordinate-complete buffer cohort, explicit `--geo-only`. For example:

## Independent external cohorts

Run these stages in order:

```bash
python run_strengthening.py external-counts
python run_strengthening.py external-source-verify
python run_strengthening.py external-predictions
python run_strengthening.py external-metrics
python run_strengthening.py external-calibration
python run_strengthening.py external-followup
python run_strengthening.py external-calendar
python run_strengthening.py external-sensitivity
python run_strengthening.py external-secondary
python run_strengthening.py external-freeze
```

`external-counts` creates the initial system-source proxy cohort. **`external-source-verify` is required**: it preserves the proxy version and adopts the official Washington per-source classification as canonical v2. Primary v2 has Michigan 1,283 systems/25 positives and Washington 855/84. The endpoint is either PFOA or PFOS at a retained-location mean >=4.05 ng/L after re-censoring reported concentrations below 4 ng/L to zero. Use the first two groundwater/four surface collection dates in 2023-01-01–2026-06-30 when their span is <=366 days, without outcome-based date selection. This count rule is not an annual regulatory-compliance schedule. Michigan has a current-system source-class proxy; Washington uses verified source classes and explicitly action-level-coded analyte records.

Washington's public integer display has no documented nearest-integer rounding rule. The +/-0.5 analysis therefore produces a **hypothetical assumption scenario**, not identified true-label bounds or a confidence interval. Additional same-name PFOS records without action-level metadata have unresolved identity; max/sum alternatives are sensitivity analyses, not inferred isomer corrections. Minnesota maxima/minima and New Hampshire raw-source flags are secondary endpoint-mismatched ranking checks and cannot validate retained-mean calibration.

Follow-up eligibility is associated with initial >=4 ng/L results. Its early-index restriction uses 366 days before the earlier of the actual state sampling endpoint and the common window end (MI2024-12-23; WA2025-06-29), rather than assuming a later nominal date is observed. These state cohort fractions are conditional on screening/follow-up and current inventory matching, not statewide burden. Calendar and minimum-span alternatives produce different selected cohorts; the paired shared-location analysis holds the comparison universe fixed. The primary AUC interval resamples 0.5-degree administrative-centroid blocks; system bootstraps are secondary. Both are conditional on the observed external cohort. National-ratio whiskers propagate national calibration-factor uncertainty only, with the target cohort fixed. No external outcome is used for fitting, calibration or model selection.

The completion extension uses fixed first-stage scores and positive unit-specific q. Bounded aggregate reported-result CSVs are included under `strengthening/reference_results/`. They contain no system-level prediction frame or raw state sample records. The aggregate ROC path was computed from the fixed observed-cohort scores; distributing its points avoids including the 970 individual prediction rows merely to redraw the plot.

This redraws reported figures from frozen aggregate inputs; it does not refit or independently validate the models. Existing different files are protected unless `--force-reference` is explicitly passed. Plot scripts use the publication kit, exact `nature_new` colours, native typography and alignment/palette checks, 600-dpi PNG/PDF, `CHONG LIU` metadata and independently redrawn semantic panels. All figure text uses normal weight, including tick labels, axis labels, panel letters, legends and annotations; original font sizes are retained. The current compact-layout update reduces physical panel/legend whitespace and canvas heights while preserving reading-essential labels, symbols and intervals; main figures retain three content rows. Its source and export checks are recorded in `strengthening/COMPACT_LAYOUT_VALIDATION.json`. The subsequent screenshot-targeted adjustment changes only Fig.1a's internal map/zoom arrangement and the main Fig.7 column gutter. It retains the geographic projection, all observations, labels, normal font weight, font sizes, colours and quantitative inputs. Fig.S6 and other figures retain their previous layouts; targeted checks are recorded in `strengthening/TARGETED_WHITESPACE_VALIDATION.json`. Quantitative plots do not use image generation. Main figures have three content rows. Detailed information-boundary and uncertainty definitions belong in the manuscript/SI Methods and Results as well as these code notes.

The compact method renderer additionally accepts `--data-root` for its four aggregate input tables, `--output-root` for a folder containing `figures/`, and `--qa-root` for its audits and selected source rows (default: `<workdir>/figure_QA_regular`). Final Fig.7 includes the same-depth PPS completion comparator. Method helper copies are versioned alongside that renderer; the shared historical plotting style and current renderers have the same normal-weight preference.

`run_current_figures.py` is the figure dispatcher for the current version. Its default set is the six replaced figures (2,6,7,S4,S5,S6), routed to the new modules. Explicit `--only 1 3 4 5 S1 S2 S3` calls the preserved base code for unchanged figures. Because that code imports the complete historical figure system, it requires the historical `figure_data` dependency set, regenerated with the original `figure-data` stage or supplied via `--legacy-data`; large system-level figure inputs are not redistributed. The graphical abstract is a retained schematic asset with its separate source/prompt provenance and is not regenerated by statistical plotting commands.

Validation of the original source-only portability adaptation is recorded in `strengthening/VALIDATION.json`. The normal-weight figure-only revision is checked in `strengthening/REGULAR_WEIGHT_VALIDATION.json`; the subsequent compact-layout revision has its own `strengthening/COMPACT_LAYOUT_VALIDATION.json`. Both preserve the numerical analysis and aggregate data. Earlier validation reports describe their historical release, not the later layouts. Raw monitoring downloads, source/contact workbooks, manuscripts, fitted models and 66k-system predictions are not distributed. Public source URLs may change; compare snapshot SHA256 values before claiming numerical reproduction.

## Same-depth classical control and final figures (31 October 2026)

```bash
python -m strengthening.method.external_neyman_two_phase --cohort <external_schedule_systems.csv> --primary <external_primary_R12_B300.csv> --out <folder>
python run_strengthening.py install-reference --workdir reproduced_plots
python render_upgraded_figures.py --workdir reproduced_plots
```

The control uses the strata, stratum standard deviations and integer plans of the full-schedule five-stratum Neyman references, with expected unit cost q·c_full + (1 − q)·c_R12 (q = 0.2), budgets of 100 and 300 full-schedule equivalents and 1,000 draws. Point estimates use the same two-phase difference estimator as the other designs; the variance uses the Poisson approximation with π = n_h/N_h, which is conservative for stratified selection. No external outcome forms strata or allocations. `external_schedule_systems.csv` is written by `strengthening/external/build_external_cohorts.py` from the state downloads and is not redistributed.

`render_upgraded_figures.py` reads only the aggregate tables installed by `install-reference` (including the Fig. 5 burden tables and the same-depth control) and reproduces the submitted Fig. 5, Fig. 7 and graphical abstract pixel for pixel.
